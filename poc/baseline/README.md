# Shared metric and baseline

The installable `squares` package, exact grids, small-n search and official-metric regression tests. Python package metadata, source, examples and upstream license notices are inside `poc/`.

Run from the repository root after installing the shared package.

```sh
python -m pip install -e './poc/baseline/poc[dev,optimize,records]'
squares --help
```

[Detailed usage](docs/USAGE.md).
