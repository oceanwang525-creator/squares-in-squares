# Working notes

## Geometry

Four rigid `a x b` blocks (`a,b` integers, `a >= b`) are generated by one
rotation of a base block and 90-degree copies:

```
base centre (dx, dy), base angle theta
block_k = R(k*90) . base,  theta_k = theta + k*90
```

Unit cells of a block are the `a*b` cells in its own frame, so their angles are
`theta_k` (rigid). Fill cells are upright (`angle = 0`) integer-lattice cells.

Pair feasibility uses SAT with the four candidate axes (two per rectangle);
positive gap `> 1e-3` is required for anything that must not touch. The official
metric is the final authority, and it accepts exact contact as separated.

## Side

`L = max(extent_x, extent_y)` over all block vertices after translating the
minimum corner to the origin. Fill never changes `L`: it is placed strictly
inside `floor(L)` and the blocks already span the bounding box.

## Why tilt cannot help this family

For a fixed centre distance the four centres are a 4-fold orbit. Rotating each
rigid block by `theta` about its own centre turns the outer corners outward into
the axis-aligned bounding square; the bounding side is monotone non-decreasing
in `|theta|` while capacity (block area) is unchanged. Scanning confirms it: at
every target the minimum-`L` capacity-matched member has `q = 0`, i.e. the
degenerate (untilted) member is the best. So the "rational slope" is a
strictly-losing direction for this 4-fold gadget.

## Fill accounting

`fill_cells` computes, for each candidate lattice cell, the minimum over the
four SAT axes of the separation gap to each block; a cell is kept if that
minimum clears `1e-3` for all four blocks. Capacity is `4ab + kept`. Because a
cell only needs to clear the blocks (fill cells are on the integer lattice and
never overlap each other), this is exact bookkeeping for the emitted set.

## Emission safety

All contacts are opened by scaling every centre about the origin by
`1 + 2e-6`. Unit sizes and angles are untouched. This is the same device the
repository's `prepare_kaggle` uses; it makes the literal and the pandas
round-trip both certifiably non-overlapping without changing `L` materially
(≈ `2e-6 * L`, visible only in the last digits).

## Scan

`run.py` scans `31,405` configurations (`a in 2..12`, `b in 1..a-1`, 12 slopes,
30 centre distances, 2 families) and records, per target, the minimum `L` among
capacity-matched members. The emitted `best` rows are that minimum; the
`tilted` rows restrict to `q != 0` to isolate the slope's effect.
