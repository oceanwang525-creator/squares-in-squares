# Boundary zipper

Boundary-connected seam augmentation with finite MILPs. All six bounded insertion models were infeasible; saved outputs are explicitly grid fallbacks, not wins.

Run from the repository root after installing the shared package.

```sh
python poc/boundary_zipper/poc/boundary_zipper.py --help
```

[Measured report](docs/boundary_zipper.md). Saved CSVs and results are in `data/`.
