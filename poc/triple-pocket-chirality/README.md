# Triple-pocket chirality

## Idea

The dual-pocket scans kept both source pockets intact. The four-half experiment
then split both pockets and lost too many contacts. This middle ground keeps
one complete 101- or 136-square pocket and splits the other only once.

The resulting three rigid blocks choose three of the four corners, all eight
dihedral transforms and half-unit phases. The remaining upright region is
filled exactly.

## Files

- `poc/scan.py` - three-block placement search and exact refill.
- `docs/NOTES.md` - run settings and results.

No `final.csv` is included unless the target packing is certified.
